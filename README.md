# Zindan Efsanesi

Python ve Tkinter ile yazılmış basit bir RPG zindan oyunu.

## Özellikler
- İsim ve sınıf seçimi (Savaşçı, Büyücü, Haydut)
- Can, mana, iksir ve d20 zar mekaniği
- Kılıç savurma efekti ve ekran sarsıntısı
- 3 canavar: Goblin, İskelet, Ejderha

## Çalıştırma
   python Zindanoyunu.py

Ek kütüphane gerekmez, sadece Python 3 yeterli.
